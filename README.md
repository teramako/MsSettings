# MsSettings

[Launch Windows Settings] using friendly names or ms-settings URIs from PowerShell

[Launch Windows Settings]: https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-settings

## Commands

### Open-MsSetting

```
Open-MsSetting [[-Name] <String>] [<CommonParameters>]

Open-MsSetting -Url <String> [<CommonParameters>]
```

### Get-MsSetting

```
Get-MsSetting [[-Category] <String[]>] [<CommonParameters>]
```
